«Сервис» — программное обеспечение, принадлежащее Правообладателю, через которое реализуется услуга по оплатам за пределами РФ с помощью мобильного приложения и чат-бота в Телеграм https://t.me/BeriPay_bot.

«Личный кабинет (ЛК)» — раздел Сервиса, созданный для отображения информации для Пользователя, включая детализацию взаиморасчетов, баланс, уведомления, статистику, отчеты и прочую информацию в реальном времени.

«Виртуальная карта» — платёжный инструмент, доступ к которому предоставляется Пользователю через Сервис на сумму пополнения для оплат за пределами РФ. «Перевод» — действия Пользователя с использованием Сервиса для осуществления расчетов за пределами РФ.

«Рекуррентный платеж» — автоматическое списание средств с сохраненного счета Пользователя для пополнения баланса Виртуальной карты при недостаточности средств.
